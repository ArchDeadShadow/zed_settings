# Zed Editor Settings and Resources

This repository contains a comprehensive collection of configuration files and resources for the [Zed](https://zed.dev/) text editor. It is designed to help you personalize and enhance your Zed experience with custom settings, keyboard layouts, fonts, and visual themes.

## Contents

- **config/**
  - **settings** — User and workspace settings to customize editor behavior and appearance.
  - **keymap** — Custom keyboard layouts and keybinding configurations for improved productivity.
- **resources/**
  - **font** — Font files and recommendations for better code readability and aesthetics.
  - **theme** — Visual themes to change the look and feel of the editor interface.

## Usage

1. Clone or download this repository.
2. Copy the desired folders or files into your Zed configuration directory (usually `~/.config/zed/`).
3. Restart Zed to apply the new settings and resources.
